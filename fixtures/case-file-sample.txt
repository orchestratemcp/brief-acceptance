## OpenClaw subscription and access restrictions
P1 [cites E1, E2, E3, E7]: Several reports describe major AI companies limiting how their subscription plans can be used with OpenClaw, a competing tool. Anthropic told Claude Code subscribers they could no longer use their subscription limits for third-party tools such as OpenClaw starting in early April, requiring a separate pay-as-you-go charge instead, though a later report says Anthropic reversed course and allowed OpenClaw-style Claude command line usage again later that month. Google was also reported to be restricting its AI Pro and Ultra subscribers from using OpenClaw. These posts drew very heavy engagement, with well over a thousand reactions and hundreds of comments each.

## OpenClaw general reception
P2 [cites E4, E5, E6, E8, E9, E10]: OpenClaw continues to generate strong and mixed discussion. Some posts praise it, including one saying it is what Apple's intelligence features should have been and another describing it as life changing for the user. Others raise concerns, including a report of a privilege escalation vulnerability and a post calling it a security risk disguised as something exciting. There is also confusion about its identity, with one post noting it is a renaming of a product previously called Moltbot, and another asking who actually uses it, with the poster noting that nobody in their own circle does despite feeling very engaged with the AI world.

## OpenClaw feature requests
P3 [cites E23, E24, E25]: Users have asked for several practical improvements to OpenClaw. One request asks for a configurable timeout threshold for the streaming watchdog, since models that reason for a long time before responding can trigger false alarm warnings. Another asks for a denylist option for command approvals, so that most actions could be allowed automatically except for specifically risky ones like sending or deleting emails and messages. A further request asks for support for rendering mathematical formulas properly in the control interface, rather than showing raw formula code.

## Hermes Agent product discussion
P4 [cites E12, E15]: Hermes Agent, an open source AI agent with persistent memory, was discussed on Hacker News, along with a related post about adding Grafana-based observability tools for monitoring Hermes agents.

## Hermes Agent feature requests
P5 [cites E11, E13, E14, E16, E17, E18, E19, E20, E21, E22]: A large number of feature requests have been submitted for Hermes Agent. Users want a way to use a Claude subscription as the model backend without paying twice, following a change where Anthropic is separating subscription usage from a new monthly credit system for developer tools starting in June 2026. Other requests include automatic backup and version control for the agent's stored data, support for an additional web search tool called Searxng, the ability to run the agent remotely while keeping tool execution on a local machine, support for Mistral as an additional model provider, and a more general way to connect Hermes with other coding assistant tools. Further requests ask for tiered permission levels so a shared Hermes assistant could restrict what different users are allowed to do, a native mobile app with voice calling, cloud syncing of settings and data across multiple devices, and a technical change to load tool information only when needed, in order to reduce processing time and cost.
